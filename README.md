### 🚀 Qué hago

Construyo productos web de punta a punta para negocios reales: **e-commerce y catálogos con precios en doble moneda (USD/Bs)**, **paneles administrativos**, **SaaS multi-tenant** y **apps en tiempo real**. Me encargo del análisis, la arquitectura, el desarrollo, el despliegue en VPS y la gestión del proyecto con el cliente.

- 🛒 Tiendas y catálogos con panel admin (inventario, pedidos, clientes, analíticas)
- 🔧 Sistemas de gestión: talleres, torneos deportivos, operaciones internas de agencias
- ⚡ Tiempo real con WebSockets / Socket.IO
- 🐳 Despliegue con Docker, nginx, PM2 y Let's Encrypt
- 📋 Gestión de proyectos y trato directo con clientes
